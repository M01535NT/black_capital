05Referencia técnica

Tokens para handoff

Bloque de variables listo para producción. Se declara una vez en el elemento raíz; todos los estilos inline lo referencian con var(--token, fallback).

:root {
  /* superficies */
  --bg:     #050505;
  --panel:  #0A0A0A;
  --footer: #000000;
  /* texto */
  --ink:    #FFFFFF;
  --muted:  #CFCBC1;
  --line:   rgba(255,255,255,.22);
  /* marca */
  --acc:     #CFA652;
  --acc-rgb: 207,166,82;
}

Display : 'Archivo'     800 / 900   (mayúsculas, tracking -.01/-.02em)
Texto   : 'Public Sans' 400–700

Sección : padding 84px 48px  ·  grid gap 24px  ·  radios 2/4/6/8/pill
Botón   : 1 primario por vista · hover brillo +8% · active +1px
